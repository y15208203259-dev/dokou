# 渡口
 [下载渡口 Windows 公测版](https://github.com/y15208203259-dev/dokou/releases/tag/v0.1.0-beta.1)
**把多个 AI 放进同一个工作台，一起讨论、分工，并调度本机外部 Agent。**

渡口是一个本地优先的多 AI 协作工作台。你可以为不同成员配置模型接口、角色提示词和头像，让它们在同一段会话中交流，把讨论推进成任务，并在界面里查看工具调用、确认请求和交付成果。

目前提供 **Windows 桌面公测版**，也可以从源码启动浏览器版。项目仍在持续完善，欢迎通过 Issues 提交使用反馈。

> 本地优先指会话数据库和成果主要保存在你的电脑上。使用在线模型、网页工具或远程 MCP 时，相关内容仍会发送给你配置的服务。

## 可以做什么

| 功能 | 说明 |
| --- | --- |
| 多模型成员 | 为成员分别配置接口、模型、提示词、头像、视觉能力和推理档位；支持内置角色预设与自定义成员。 |
| 单聊与群聊 | 在同一个对话流里交流和推进任务；可以点名成员、邀请成员、继续讨论及在执行中补充要求。 |
| 群聊交互 | 拖动成员头像调整发言顺序，勾选“自由发言”后随机排序；可按会话开关分段气泡。 |
| 任务与成果 | 提交和确认计划、派活给成员、查看任务状态；成果按版本保存，可预览和下载。 |
| 工作区与记忆 | 按项目组织会话和工作项，切换独立数据工作区；成员记忆按成员隔离，可跨会话使用。 |
| 本机工具 | 读取和搜索工作区文件、写入文件、运行代码或命令、抓取网页、操作浏览器及管理后台任务；可用范围受执行路径、权限和依赖影响。 |
| 图片与视频 | 视觉成员可接收图片；视频工具支持探测、抽帧和查看细节，也可通过本地语音转写查找内容。 |
| 工具扩展 | 接入外部 HTTP 工具、MCP 服务器，并读取本机 DSH 技能。 |
| 外部 Agent | 通过 ACP 接入 DSH、Codex 等本机外部代理，派发任务并在工作台查看进度、确认请求和结果。 |

成员使用哪些模型、承担什么分工，都由你决定。角色预设与模型接口配置相互独立。

## 下载与启动

### Windows 桌面版

1. 打开本仓库的 **Releases（发行版）** 页面，下载公测 ZIP 压缩包。
2. 完整解压到有写入权限的文件夹，例如 `D:\渡口`。
3. 双击 `渡口.exe`，首次启动可能需要稍等。
4. 先用“本地演示”熟悉流程，再配置自己的模型接口。

桌面版已包含 Python 运行环境，基本使用无需另装 Python。界面依赖 **Microsoft Edge WebView2 Runtime**；若系统提示缺少，请从[微软官方网站](https://developer.microsoft.com/microsoft-edge/webview2/)安装。

当前公测程序未做数字签名。遇到 Windows 安全提示时，请先核对下载来源和发行说明。

### 更新桌面版

退出渡口，将新版 `渡口.exe` 替换到原文件夹，再重新打开。保留同目录下的 `data` 文件夹，即可继续使用原有会话和配置。覆盖前建议备份数据。

目前没有自动更新功能。

## 配置第一个模型成员

1. 打开成员列表，添加成员或编辑已有成员。
2. 填写**接口地址、模型名称和接口协议**，并填写你自己的 API Key。
3. 保存后发送一条简单消息，确认对话能正常返回。
4. 如需分析图片或视频画面，确认所用接口与模型支持图片输入，再勾选“视觉模型”。

支持的接口协议：

| 协议 | 地址示例 |
| --- | --- |
| OpenAI Chat Completions | `https://api.example.com/v1` 或完整的 `/v1/chat/completions` 地址 |
| OpenAI Responses | `https://api.example.com/v1` 或完整的 `/v1/responses` 地址 |
| Anthropic Messages | 服务商提供的基础地址或完整的 `/v1/messages` 地址 |
| 自动识别 | 按地址选择协议；遇到兼容问题时，请手动选择服务商要求的协议。 |

以上域名仅为格式示例。请使用服务商实际提供的地址和模型 ID。模型列表能读取，不代表对话、工具调用或视觉能力一定可用；这些还取决于服务商实现、账号权限及模型本身。

渡口不附送模型额度或订阅。调用真实模型可能产生费用，多成员讨论也会分别调用参与成员的接口。

## 从聊天推进到任务

- **直接聊天：** 在单聊或群聊里输入消息，无需切换“闲聊／任务”模式。
- **定向请求：** 在输入框使用 `@` 选择成员，交给指定成员处理；点名不改变群聊的排序设置。
- **多人讨论：** 邀请成员加入会话，使用全员讨论入口征集意见。普通群聊中成员可能不参与每一轮。
- **开始执行：** 说明要完成什么、交付什么以及限制条件；复杂任务可先提交计划，由你确认后继续。
- **执行中补充：** 新要求会进入后续执行上下文；已经发出的模型请求通常需要等返回或超时。
- **查看交付：** 在成果区查看、下载结果，并继续提出修改要求。

普通群聊使用有预算限制的只读工具循环，主要用于查看文件和讨论。需要写文件、运行命令、分析视频或调用外部代理时，请在会话中点名成员执行。

## 视频与扩展能力

这些能力按需配置，基本聊天不要求安装全部依赖。

| 能力 | 额外条件 |
| --- | --- |
| 视频信息、抽帧与局部查看 | 本机安装 `ffmpeg`、`ffprobe` 并加入 PATH；分析画面还需要成员启用视觉能力，且模型接口支持图片输入。 |
| B 站视频 | 可直接向视频工具提供视频页面链接，工具会尝试解析、下载并缓存；部分视频可能需要在设置中导入 B 站 Cookies，或受登录、地区及访问限制影响。 |
| 视频下载回退 | 直接解析失败时尝试本机 `yt-dlp`；该程序需要另外安装并加入 PATH。 |
| 音频／视频转写 | 本地 `faster-whisper` 及对应模型；首次使用可能需要下载模型。 |
| MCP | 自行配置 MCP 服务器及其运行环境；支持本机 stdio 和 HTTP 接入。Node、Python 等要求由对应服务器决定。 |
| DSH 技能 | 读取本机技能目录中的方法说明；技能所需的程序、模型或服务仍需另行准备。 |
| 外部 Agent | 安装并配置对应代理及 ACP 适配器；部分启动链需要 Node.js、npm／npx。 |

视频工具通过抽取静态画面分析内容，快速动作、细小文字或短暂出现的内容可能需要进一步局部查看。网页抓取返回的页面文字不能代替视频画面。

当前桌面公测包附带角色素材及部分 DSH 技能。首次启动会补充缺失文件，不覆盖已有同名文件。技能默认补入 `~/.dsh/skills`，可通过 `DSH_SKILLS_DIR` 指定其他目录；素材补入客户端的数据目录。

外部代理目前主要围绕 DSH 与 Codex 接入。不同电脑上的安装路径、登录状态、适配器版本及网络环境会影响连接；**握手成功也不代表模型鉴权和实际任务执行一定成功**。Codex 跨机连接仍在收集公测反馈，其他 ACP 代理尚需分别适配与验证。

## 权限与数据

### 三档执行权限

| 档位 | 行为 |
| --- | --- |
| 仅可查看 | 阻止写入、执行命令等危险工具。 |
| 工作区内修改 | 危险工具通常需要在界面确认后执行。 |
| 完全权限 | 危险工具可直接执行，并保留执行记录。 |

这些是应用内的权限策略，**不是操作系统级沙箱**。运行代码、命令、浏览器操作及外部工具会使用本机进程的实际权限；执行前请核对路径、参数和权限设置。

### 数据保存位置

| 运行方式 | 默认位置 |
| --- | --- |
| Windows 桌面版 | `渡口.exe` 同目录下的 `data/`，包含数据库、上传文件、工作区文件、素材、窗口资料和日志。 |
| 源码浏览器版 | 项目下的 `.multi_ai_workspace/` 保存数据库与配置，`工作区文件/` 保存工作文件和上传内容。 |
| 自定义目录 | 后端可通过 `DUKOU_DATA` 指定数据根目录。 |

模型 API Key 保存在当前浏览器或桌面窗口的本机存储中，按成员和接口地址关联；运行时传给后端，并用于请求对应模型服务。它们不作为成员配置写入 SQLite，**但本机存储本身未加密**，桌面窗口资料也应按敏感数据保护。

清除网站数据、删除窗口资料、换浏览器或移动运行目录，可能需要重新填写密钥。复制整个数据目录也可能包含敏感窗口资料，请勿公开上传。

备份前先退出程序。桌面包提供的 `备份数据.bat` 会备份业务数据并排除窗口资料；它不用于迁移已保存的 API Key。公开反馈时不要附带 Cookies、密钥、完整数据目录或私人会话。

后端默认只监听 `127.0.0.1`，面向本机使用，不支持直接作为多人公网服务部署。

## 从源码运行

建议使用 **Python 3.11**。基础浏览器版的服务与协议适配使用 Python 标准库；桌面窗口和媒体等扩展能力另有依赖。

在项目根目录执行：

```powershell
python server.py
```

浏览器打开 <http://127.0.0.1:8765>。Windows 下也可双击 `启动协作台.bat`；该脚本会在后端退出后尝试重新启动，彻底停止时需关闭其命令窗口。

如需使用其他端口：

```powershell
$env:COLLAB_PORT = "8875"
python server.py
```

同一数据目录不要同时启动多个服务。后端重启后刷新页面，取得新的本机会话凭据。

从源码运行桌面窗口：

```powershell
python -m pip install pywebview
python dukou/app/window.py
```

源码桌面窗口默认使用 `dukou/data/` 和端口 `8766`。

### 目录结构

```text
.
├── server.py                 # 浏览器版后端、成员调度与工具执行
├── index.html                # 浏览器版界面
├── model_protocols.py        # 三类模型接口协议适配
├── tools/                    # ACP 侧车等配套工具
├── dukou/
│   └── app/                  # 桌面窗口入口与客户端源码副本
├── .artifacts/               # 角色资源、构建脚本及开发产物
│   └── software/build_exe.py # Windows 客户端构建入口
├── test_*.py                 # 后端测试
└── frontend-*.test.cjs       # 前端逻辑测试
```

浏览器版与桌面版保留两份后端和界面源码。涉及共用功能的修改，需要同步根目录与 `dukou/app/`，再重新构建桌面程序；修改源文件不会直接更新已有 EXE。

角色预设等必要资源也位于 `.artifacts/`，该目录同时含开发缓存和备份。整理源码发行范围时需要区分两者。

### 构建 Windows 客户端

在 Windows 下安装构建依赖后执行：

```powershell
python -m pip install pywebview pyinstaller pillow
python .artifacts/software/build_exe.py
```

当前构建脚本依赖项目中的角色资源，并会收集构建者本机 `~/.dsh/skills` 下的技能。分发前需要审核技能、素材、许可和包内内容，不能将任意本机目录直接视为可公开发布资源。

构建结果位于 `.artifacts/software/exe_build/dist-feedback/`，不会自动替换正式客户端或更新发行版 ZIP。

## 已知限制与反馈

- 当前为 Windows 公测版；其他桌面系统尚未提供安装包。
- 不同模型和中转服务的工具调用、视觉输入及协议兼容性存在差异。
- 群聊讨论与点名执行的工具范围不同，不是每条群消息都会启动完整任务执行。
- 视频、语音、MCP 和外部代理依赖额外环境，并非开箱即可运行全部功能。
- 模型回复与工具结果仍需核对，重要成果建议另存一份。
- 暂无自动更新，也未提供面向公网部署的账号与多用户隔离机制。

提交 Issue 时，请提供：

1. 使用的版本、Windows 版本，以及桌面版或源码版。
2. 复现步骤、预期结果、实际结果及相关截图。
3. 涉及模型时，注明接口协议和模型名称；涉及外部代理时，附失败步骤与脱敏错误文字。

请先移除 API Key、Cookies、个人路径和私人会话内容。无需提交整个数据目录。

## 开发与贡献

欢迎提交问题和改进建议。修改时请保持浏览器版与桌面版的共用实现同步，并为影响执行、权限、协议或数据持久化的变更补充针对性验证。

后端测试可在项目根目录执行：

```powershell
python -B -m unittest discover
```

部分测试依赖额外工具或使用临时服务。浏览器端验收脚本可能创建测试成员、会话或成果，请在独立测试工作区运行。测试通过不等同于所有模型、第三方服务和干净 Windows 环境均已验证。

项目名称和角色预设用于界面展示，不代表相关模型厂商的官方产品或背书。代码、第三方依赖、技能与角色素材的使用范围，应分别以各自适用的授权为准。
